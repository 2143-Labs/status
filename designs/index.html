Status design gallery

Workshop for status.2143.me. Production stays on its own host; this is where designs are reviewed.

  • Map

    Diagram-first: the live map as the page, then components, drills and incidents.

  • Document

    Calmer, denser: summary cards, collapsible groups, today/target table.

  • Live renderer

    The shipped page on fixture data — summary cards, state pills, latency, and 90-day bars that separate “no history yet” from “nobody reported”. live-normal.html, live-incident.html.

  • Demo · Diorama

    Isometric estate: buildings are machines, floors are their workloads, the ground is 90 days of history. Drag the timeline to replay.

  • Demo · Lab

    A top-down lab: one building per provider, a room per region. Ingress along the top wall, racks in the middle, services at the bottom; links run between buildings. Toggle Today / Target to see the edge rollout.

  • Demo · Flow

    The request path, live: internet → load balancer → cluster → WireGuard → router → services, with per-hop latency.

  • Demo · Rack

    Hardware first: each machine as a rack unit, its CPU and RAM packed with the fungible workloads using them.

  • Demo · Console

    Keyboard first: press / and type what you want — a node, a metric, "slowest hop", "down 7d".

Every PR gets a preview at status-{N}.john2143.com. This page tracks main. Demos take ?scenario=, ?layout=today|target, ?seed=, ?speed=, ?t= and ?plain.
